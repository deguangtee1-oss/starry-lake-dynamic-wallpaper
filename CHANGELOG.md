# 星夜湖畔动态壁纸 | Starry Lake Dynamic Wallpaper

以下记录根据本地版本视频、现有脚本和 Obsidian 项目记录整理。V7–V11 视频现已作为公开 GitHub Release 附件提供；素材许可范围见 docs/asset-rights.md。

## V11

- 基于 V10，在月亮右侧增加一颗小型、无尾迹、缓慢向左下移动的点状星星，并在循环边界前渐隐。
- 保留 V10 流星和视频中已经合成的其他画面。

## V10

- 基于 V9，将两条流星的总体运动方向统一为右上至左下，同时保留原有时间安排与视觉参数。

## V9

- 基于 V8，修补检测到的旧流星痕迹，重新绘制两次独立流星运动，并输出 30 FPS。

## V8

- 现存的精细版脚本在内缩湖面遮罩内添加低幅度、局部的反光亮度变化。
- 保留早期实验脚本作为历史记录；其湖面遮罩较宽，不作为推荐重建流程。

## V7

- 用户提供的源 MP4；该视频是合成后的壁纸画面，未找到分层工程和确切的原始生成脚本。
- V7 源视频与 V8–V11 视频已在 GitHub Release 提供下载。

## English

These notes are based on the local video versions, available scripts, and the Obsidian project record. V7–V11 videos are now available as public GitHub Release assets; see docs/asset-rights.md for the media terms.

## V11

- Based on V10, adds a small, tail-free point star to the right of the moon. It drifts slowly down-left and fades near the loop boundary.
- Preserves the V10 meteors and the other content already composited into the video.

## V10

- Based on V9, aligns both meteors to an overall upper-right-to-lower-left direction while retaining their existing timing and visual parameters.

## V9

- Based on V8, repairs detected old meteor traces, renders two separate meteor events, and outputs at 30 FPS.

## V8

- The available refined script adds low-amplitude, local reflection-brightness variation inside an inset lake mask.
- The early experimental script is retained as a historical record. Its water mask is broader, so it is not part of the recommended rebuild.

## V7

- User-provided source MP4; the video is a composited wallpaper image. No layered project or exact original generation script was found.
- The V7 source and V8–V11 videos are downloadable from the GitHub Release.
