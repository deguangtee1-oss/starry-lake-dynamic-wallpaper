# 壁纸 | Wallpapers

## 中文

最终 MP4 作为 GitHub Release 附件提供，没有提交到常规 Git 历史。可从项目的 wallpaper-media-v7-v11 Release 下载 V11，或使用有权处理的 V7 输入在本地构建。图片和视频的公开范围见 docs/asset-rights.md。

## English

The final MP4 is available as a GitHub Release asset and is not committed to normal Git history. Download V11 from the project's wallpaper-media-v7-v11 Release, or build locally from a V7 input that you are authorized to process. See docs/asset-rights.md for the publication scope of images and videos.
