# Lively Wallpaper 安装与设置 | Lively Wallpaper Setup

## 中文

1. 从项目的 wallpaper-media-v7-v11 GitHub Release 下载 Starry_Lake_Wallpaper_V11.mp4。
2. 打开 Lively Wallpaper，选择 **Add wallpaper** 并选中下载的 MP4。
3. 选中导入的动态壁纸，应用到要使用的显示器。
4. 在 Lively 设置中检查缩放、显示器分配和循环播放效果。

当前 V11 为 1280×720、30 FPS、8 秒、H.264。导入或播放失败时，先确认文件已完整下载且 Lively 能读取该 MP4。

## English

1. Download Starry_Lake_Wallpaper_V11.mp4 from the project's wallpaper-media-v7-v11 GitHub Release.
2. Open Lively Wallpaper, select **Add wallpaper**, and choose the downloaded MP4.
3. Select the imported animated wallpaper and apply it to the desired display.
4. Check scaling, display assignment, and looping in Lively's settings.

V11 is 1280×720, 30 FPS, 8 seconds, H.264. If importing or playback fails, first verify that the file downloaded completely and that Lively can read the MP4.
